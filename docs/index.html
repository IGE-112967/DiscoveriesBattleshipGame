Battleship Game

Projeto Java/Maven da Batalha Naval com Docker, GitHub Actions e documentação publicada.

Descrição

Este projeto implementa uma versão simples do jogo Batalha Naval em Java. Usa Maven para compilação e documentação, Docker para distribuição da aplicação e GitHub Actions para automatizar a publicação da imagem no Docker Hub.

Docker

A imagem Docker está publicada no Docker Hub:

Docker Hub - ige112967/battleship-game

Para descarregar e executar:

docker pull ige112967/battleship-game:latest
docker run -it --rm ige112967/battleship-game:latest

GitHub Actions

O projeto inclui um workflow GitHub Actions que constrói o projeto, gera a imagem Docker e publica automaticamente essa imagem no Docker Hub.

Projeto desenvolvido no âmbito da unidade curricular de Engenharia de Software.
